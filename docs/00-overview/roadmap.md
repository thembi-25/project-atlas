# Roadmap (Executive Summary)

This is a high-level pointer document. The authoritative, detailed roadmap lives in [`13-roadmap/implementation-roadmap.md`](../13-roadmap/implementation-roadmap.md), with one file per phase.

## Phase sequencing at a glance

| Roadmap Phase | Focus | Long-term pillar | Detail |
|---|---|---|---|
| Phase 1 | Foundation: architecture, multi-tenancy, identity, organizations, users, permissions | Prerequisite for all pillars | [phase-1-foundation.md](../13-roadmap/phase-1-foundation.md) |
| Phase 2 | Core Operations: CRM, properties, assets, jobs, scheduling, dispatch, estimates, invoicing, payments, inventory | Pillar 1: Core Operations | [phase-2-core-operations.md](../13-roadmap/phase-2-core-operations.md) |
| Phase 3 | Property Intelligence: richer asset lifecycle, service history insight, predictive signals | Pillar 2: Property Intelligence | [phase-3-property-intelligence.md](../13-roadmap/phase-3-property-intelligence.md) |
| Phase 4 | Supplier Marketplace | Pillar 3: Supplier Marketplace | [phase-4-marketplace.md](../13-roadmap/phase-4-marketplace.md) |
| Phase 5 | Manufacturer Integrations & Warranties | Pillar 4: Manufacturer Integrations | [phase-5-manufacturers.md](../13-roadmap/phase-5-manufacturers.md) |
| Phase 6 | Financial Services | Pillar 5: Financial Services | [phase-6-financial-services.md](../13-roadmap/phase-6-financial-services.md) |
| Phase 7 | Industry Data Network | Pillar 6: Industry Data Network | [phase-7-industry-network.md](../13-roadmap/phase-7-industry-network.md) |

Each phase is strictly dependent on the ones before it — see [Implementation Roadmap](../13-roadmap/implementation-roadmap.md) for the explicit dependency graph. Phase 1 and the beginning of Phase 2 are further broken into [Sprint 0](../13-roadmap/sprint-0.md), [Sprint 1](../13-roadmap/sprint-1.md), and [Sprint 2](../13-roadmap/sprint-2.md).

## What "launch" means

Launch is the completion of Phase 2 (Core Operations) on top of Phase 1 (Foundation). Phases 3–7 are explicitly post-launch and are not built simultaneously with launch scope — see [Product Scope](../01-product/product-scope.md) and [Business Objectives](./business-objectives.md).
