# Migrations

Generated by `pnpm db:generate` (Drizzle Kit), applied by `pnpm db:migrate`. See
[`docs/04-database/migrations.md`](../../../docs/04-database/migrations.md).

This directory is intentionally empty as of Sprint 0 (Engineering Foundation) — the
schema in `../src/schema/index.ts` defines no tables yet, so there is nothing to
generate a migration for. The first real migration is authored in Sprint 1
(Identity & Organizations), introducing `organizations`, `users`,
`organization_memberships`, `roles`, `permissions`, `role_permissions` — see
[`docs/13-roadmap/sprint-1.md`](../../../docs/13-roadmap/sprint-1.md).

Do not hand-write a migration file in this directory — always generate via
`pnpm db:generate` from a schema change, per the workflow in
[`docs/04-database/migrations.md`](../../../docs/04-database/migrations.md).
